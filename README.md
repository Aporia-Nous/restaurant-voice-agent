# Restaurant AI Phone Agent

Design and test record for an AI voice agent that takes restaurant pickup/delivery orders by phone: system prompt, menu and FAQ knowledge, order read-back with tax and fees, POS integration plan, failure handling (never claims an order was placed when submission fails), and transcripts of scripted test calls.

**Tech stack:** Votel voice-agent platform, prompt engineering, JSON workflow plan, scripted call tests

> **How this was built:** built fast with AI coding tools (vibe coding), then reviewed, tested, and documented by me. Demo data only: all names, numbers, and businesses are fictional.
